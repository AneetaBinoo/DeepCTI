## 4. Findings that must shape the paper

1. **The LLM does not drive DC's decisions.** In E2, DC's status equals the LLM-free S1′ in every episode, both
   arms, all six models (test and calib); in the withheld arm it also equals Trivy alone (Trivy is trusted per
   `config/source_profiles.yaml`: dev FP 0/191, FN 0/91 against the tracker). DC's advantage over ReAct comes from the provenance-tracked evidence state, trusted structured
   tools and the deterministic decision table — not from LLM reasoning. The LLM's measurable roles are
   explanation text and (exploratory E10) advisory compilation feeding risk-controlled release.
2. **A real DC failure mode**: when a package is upgraded on disk but the service is not restarted, DC says
   `fixed` from the package DB (loss 9.673 on those 180 episodes; S3 7.564, S4 5.896). Disk-state sources
   (pkgdb, changelog) are not independent of this failure; only the process view reveals it and VOI never
   consults it once pkgdb resolves the decision.
3. **Security results are positive for gating, weak as an attack study.** UDAR (episodes with an unauthorized
   disruptive execution): S3+P1 6.3% even without any attacker, S3+P3 (same ReAct agent, evidence-gated)
   0% at false-block rate 0.333 on warranted episodes; DC+P3 0% for untrusted-only and single world-group
   compromise. T4 tightness is visible: compromising the change system (k = 1) yields DC+P3 UDAR 0.333
   (1.0 on hosts with rollback); forging pkgdb+fs (m = 2 = k) 0.017. But injected text barely changed S3:
   untrusted-attacker ASR minus the benign rate of the same goal condition is −0.005 (S3+P1), so H4 mostly
   measures ordinary errors, and the (k, m) grid has few discriminating episodes.
4. **E3 (VOI) is uninformative as designed**: in the tracker arm every strategy (EC², entropy, checklist,
   LLM-chosen) decides with ≈ 2 calls (cost-to-decision 2.01 vs 2.04); greedy equals the DP optimum
   (regret 0). Ablations DC_k1/DC_nofresh/DC_noverify are decision-identical to DC on E2 (they differ on D2:
   DC_nofresh staleness error 0.978 on status-changing episodes).
5. **Exploratory E10 (blind arm, post-hoc D10)** — no tracker, no scanners: DC abstains unless a trusted
   observation decides (coverage 0.364, loss 0.318, DER 0); S3 loss 1.231 (DER 0.314). Learn-then-Test over
   hint-promoted decisions (LLM-compiled advisories) at α = 0.05, δ = 0.1 raises coverage to 0.48–0.60
   (model-dependent) with realised DER 0.013–0.018 and 94–100% of 200 CVE re-splits within α. This is the
   one setting where the model matters for DC — and it is post-hoc.
6. **Transfer (E7, VEX-Bench, 62/75 tasks)**: the evidence-state wrapper did not beat the plain harness
   (status F1 Gemma .613 vs .648, Qwen3-14B .130 vs .217; all paired CIs contain 0); it abstains on 54–73%.
7. **Legacy (E0/E1)**: all nine v0 audit claims confirmed quantitatively (e.g. controller-only 0.925 vs
   DeepCTI 0.907; effective sample ≈ 4 templates); v0 regex extraction falls from F1 1.000 to 0.339 on
   paraphrases while LLM extraction stays 0.84–0.91.
8. **Related work**: strong overlap for C2 — k-of-n independent-source corroboration for agent actions is
   claimed by TMA-NM (arXiv 2606.24322) and Pandey et al. (arXiv 2609.34245). The published EC² constant rests
   on a flawed proof (docs/VERIFICATION_LOG.md).

## 5. Recommendation for positioning

The defensible paper is about **evidence-state control and epistemic authorization as a wrapper for LLM agents**,
not about LLM reasoning: (i) a deterministic, provenance-tracked VEX controller is equivalent to a tracker lookup
when a tracker exists and dominates ReAct-style agents on loss and dangerous errors in E2 and E10, with zero
model sensitivity — but not on the upgrade-without-restart drift episodes (§4.2), where it is worse than S3/S4; (ii) evidence-conditioned gating (P3) removes unauthorized disruptive actions from an
unmodified ReAct agent at a measurable liveness cost; (iii) the guarantee is tight exactly where T4 says.
C2 must be differentiated from TMA-NM / Pandey et al. (four-valued state, Cedar compilation with a fragment
linter, deployed-VEX setting). Before submission: fix the restart-blindness (process view as a required source
for service packages), redesign D3 so attacks actually move baselines (adaptive attacks against the specific
model), design a VOI study where acquisition is non-trivial (noisy/expensive sources), run the human label audit
and practitioner study, and re-run on containers with Inspect.
